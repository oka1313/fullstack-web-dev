# 2.3.7 제인의 가게

## 예시: 제인의 온라인 의류 쇼핑몰 (Jane’s Store)

### 상황 설정
- **사용자(클라이언트)**: 브라우저에서 “Polo” 제품을 클릭함  
- **서버**: 요청을 받아 해당 제품의 세부 정보를 가져옴  
- **데이터베이스(DB)**: 제품 정보를 저장하고 있음  

<br>

## 요청과 응답의 흐름

| 단계 | 주체 | 설명 |
|------|------|------|
| ① | **클라이언트 (브라우저)** | 사용자가 `Polo` 아이템을 클릭 <br>→ 클릭 이벤트(click event) 발생 |
| ② | **클라이언트 (자바스크립트 코드)** | 클릭 핸들러(event handler)가 동작 <br>→ 서버로 요청 전송 (`GET /product?id=1`) |
| ③ | **서버 (예: server.py)** | 요청 수신 <br>→ 요청의 목적(상품 세부 정보 요청)과 ID(1)를 해석 |
| ④ | **서버 → 데이터베이스** | “id=1인 상품 정보를 주세요” 라고 DB에 질의(Query) 전송 |
| ⑤ | **데이터베이스** | 해당 상품의 정보를 조회 → 서버에 응답 반환 |
| ⑥ | **서버** | DB 응답을 받아 HTML 템플릿(View)에 데이터(`product_detail`)를 채워 넣음 |
| ⑦ | **클라이언트 (브라우저)** | 서버로부터 완성된 뷰(View)와 데이터(JSON or HTML)를 받아 화면에 렌더링 |

<br>

## 의사 코드(pseudocode) 예시

```python
# server.py
@app.route('/product/<id>')
def get_product(id):
    data = database.get_product(id)
    return render_template("product_detail.html", data=data)
```

```html
<!-- view.html -->
<div id="polo" data-id="1" onclick="getProductDetail(1)">Polo</div>

<script>
function getProductDetail(id) {
  fetch(`/product/${id}`)
    .then(response => response.text())
    .then(html => document.body.innerHTML = html)
}
</script>

```

## 전체 요청 흐름 요약
### 1) 클라이언트
- 사용자 입력(클릭, 폼 제출 등)을 감지하고
→ 요청(Request)을 서버로 전송

### 2) 서버
- 요청의 의도(예: 제품 상세보기) 와 데이터(예: id=1) 를 분석
- 데이터베이스에 질의(Query) 수행

### 3) 데이터베이스
- 서버의 요청에 맞는 데이터를 반환

### 4) 서버
- 받은 데이터를 HTML 템플릿에 주입(rendering)
- 완성된 결과를 클라이언트에 응답(Response)

### 5) 클라이언트
- 받은 데이터와 뷰를 사용자 화면(UI)에 렌더링

<br>

## 용어 정리
| 용어                    | 의미                        |
| --------------------- | ------------------------- |
| **클라이언트 (Client)**    | 사용자의 브라우저, 앱 등 요청을 보내는 주체 |
| **서버 (Server)**       | 요청을 처리하고 응답을 반환하는 프로그램    |
| **데이터베이스 (Database)** | 실제 데이터를 저장하고 관리하는 시스템     |
| **요청 (Request)**      | 클라이언트 → 서버로 보내는 메시지       |
| **응답 (Response)**     | 서버 → 클라이언트로 보내는 메시지       |
| **렌더링 (Rendering)**   | 데이터를 시각적으로 표현하는 과정        |

<br>

## 프론트엔드와 백엔드 구분
| 구분                    | 설명             | 구성 요소                 |
| --------------------- | -------------- | --------------------- |
| **Front-end (프론트엔드)** | 사용자가 직접 보는 화면  | HTML, CSS, JavaScript |
| **Back-end (백엔드)**    | 화면 뒤에서 동작하는 로직 | 서버 코드, 데이터베이스, API    |

<br>

## 핵심 정리
- 웹 애플리케이션은 클라이언트-서버-데이터베이스 구조로 구성된다.
- 클라이언트는 요청을 보내고, 서버는 데이터를 가져와서 가공 후 응답한다.
- 데이터베이스는 요청에 맞는 정보를 반환한다.
- 최종적으로 클라이언트가 데이터를 받아 사용자에게 화면을 표시한다.

### 요약 비유

> 🧍 클라이언트 = 손님  
> 🍳 서버 = 점원  
> 📦 데이터베이스 = 창고  
> 손님이 “폴로 셔츠 보여주세요”라고 요청하면,   
> 점원이 창고(DB)에서 찾아와 포장(렌더링)해서 손님에게 전달합니다.
