# 2.3.4 연습 SQL

## 1. SQL이란?
- **SQL (Structured Query Language)**  
  관계형 데이터베이스(RDB)와 통신하기 위한 **표준 질의 언어**
- **역할**
  - 데이터를 **조작** (INSERT, UPDATE, DELETE)
  - 데이터를 **조회** (SELECT)
  - 데이터 구조를 **정의/수정** (CREATE, ALTER, DROP)
- **SQL 방언 (SQL Dialect)**  
  - DBMS마다 SQL 표준을 완전히 따르지 않을 수 있음  
  - 예: PostgreSQL, SQLite, MySQL 등은 각자의 **SQL 문법(방언, dialect)** 을 가짐  
  - 따라서 시스템마다 SQL 문법의 일부 차이가 존재

<br>

## 2. 데이터 조작 (Data Manipulation)
| 명령어 | 설명 |
|--------|------|
| **INSERT** | 테이블에 새 행(Row)을 삽입 |
| **UPDATE** | 기존 행의 데이터를 수정 |
| **DELETE** | 테이블에서 하나 이상의 행을 삭제 |

**예시**
```sql
INSERT INTO users (name, age) VALUES ('Sarah', 28);
UPDATE users SET age = 29 WHERE id = 3;
DELETE FROM users WHERE id = 5;
```

<br>

## 3. 데이터 조회 (Querying Data)
| 명령어 | 설명 |
|--------|------|
| SELECT | 테이블에서 데이터를 조회 |

**예시**
```sql
SELECT name, age FROM users WHERE age > 25;
```

<br>

## 4. 데이터 구조화 (Defining Structure)
| 명령어 | 설명 |
|--------|------|
| CREATE TABLE	| 새로운 테이블 생성 |
| DROP TABLE	| 테이블 삭제 |
| ALTER TABLE	| 기존 테이블 구조 변경 |
| ADD COLUMN	| 테이블에 새로운 열 추가 |
| DROP COLUMN	| 테이블에서 열 삭제 |

**예시**
```sql
CREATE TABLE drivers (
  id SERIAL PRIMARY KEY,
  name VARCHAR(50),
  state CHAR(2),
  issued_date DATE
);

ALTER TABLE drivers ADD COLUMN license_number VARCHAR(20);
DROP COLUMN license_number;
```

<br>

## 5. 조인 (JOIN)
| 조인 종류 | 설명 |
|--------|------|
| INNER JOIN	| 두 테이블 모두에 존재하는 행(교집합)만 반환 |
| LEFT JOIN (LEFT OUTER JOIN)	| 왼쪽 테이블의 모든 행 + 오른쪽 테이블과 일치하는 행 |
| RIGHT JOIN (RIGHT OUTER JOIN)	| 오른쪽 테이블의 모든 행 + 왼쪽 테이블과 일치하는 행 |
| FULL OUTER JOIN	| 양쪽 테이블의 모든 행(합집합)을 반환 |

**예시**
```sql
SELECT vehicles.id, drivers.name
FROM vehicles
INNER JOIN drivers ON vehicles.driver_id = drivers.id;
```

<br>

## 6. 그룹화 및 집계 (Grouping & Aggregation)
| 명령어 | 설명 |
|--------|------|
| GROUP BY	| 특정 열을 기준으로 행을 그룹화	|
| SUM()	| 그룹 내 값들의 합계 계산	|
| COUNT()	| 그룹 내 행 개수를 계산	|

**예시**
```sql
SELECT state, COUNT(*) AS num_drivers
FROM drivers
GROUP BY state;
```

<br>

## 핵심 요약
|구분	| 주요 명령어 | 설명 |
|--------|------|------|
| 데이터 조작	| INSERT, UPDATE, DELETE	| 행을 추가, 수정, 삭제 |
| 데이터 조회	| SELECT	| 조건에 맞는 데이터 검색 |
| 데이터 구조화	| CREATE, ALTER, DROP	| 테이블 및 스키마 구조 변경 |
| 조인	| INNER, LEFT, RIGHT, FULL JOIN	| 여러 테이블 간 데이터 결합 |
| 그룹화	| GROUP BY, SUM, COUNT | 데이터 집계 및 그룹 단위 통계 |
