# 2.3.8 TCP/IP

## 1. 개요
**TCP/IP**는 인터넷에서 장치(컴퓨터, 서버 등)를 연결하고 데이터를 주고받기 위해 사용되는 **통신 프로토콜의 집합**이다.  
이름은 두 가지 주요 프로토콜에서 유래한다.

- **TCP (Transmission Control Protocol)** : 데이터 전송 제어 프로토콜  
- **IP (Internet Protocol)** : 인터넷 프로토콜 (주소 지정 및 경로 지정)

PostgreSQL을 포함한 대부분의 **관계형 데이터베이스 시스템**은  
이 **TCP/IP 통신 프로토콜**을 기반으로 **클라이언트-서버 간 데이터 통신**을 수행한다.

<br>

## 2. TCP/IP의 구성 요소

### 1) IP 주소 (Internet Protocol Address)
- **컴퓨터의 "주소"** 역할을 하는 식별자이다.  
- 네트워크 상에서 데이터가 어느 컴퓨터로 전송되어야 하는지를 결정한다.  
- 예시: `127.0.0.1`, `192.168.0.10`

**비유**  
우편을 보낼 때 수신자의 집 주소를 알아야 하는 것과 같다.  
즉, IP 주소는 데이터를 보낼 "목적지"를 나타낸다.

---

### 2) 포트 (Port)
- **컴퓨터 내에서 데이터가 도착해야 할 정확한 위치**를 식별한다.  
- 하나의 컴퓨터(호스트)가 여러 애플리케이션과 서비스를 동시에 실행할 수 있기 때문에  
  각 서비스마다 서로 다른 **포트 번호**를 사용한다.

**비유**  
IP 주소가 집이라면, **포트는 그 집 안의 "우편함 번호"** 나 "호실"과 같다.  
즉, 같은 주소라도 어떤 포트로 보냈는지에 따라 다른 서비스가 응답한다.

<br>

## 자주 사용하는 포트 번호

| 포트 번호 | 용도 | 설명 |
|------------|------|------|
| **80** | HTTP | 웹 브라우저에서 서버로 요청을 보낼 때 사용하는 기본 포트 |
| **443** | HTTPS | 보안 연결(SSL/TLS)을 사용하는 웹 통신 |
| **5432** | PostgreSQL | Postgres 데이터베이스의 기본 포트 (클라이언트 ↔ 서버 통신용) |

<br>

## 정리
- **TCP/IP**는 인터넷 통신의 핵심 프로토콜 집합이다.  
- 데이터 전송에는 **IP 주소**와 **포트 번호**가 모두 필요하다.
  - **IP 주소**: 컴퓨터(호스트)의 위치  
  - **포트 번호**: 그 컴퓨터 내의 특정 서비스 위치  
- **Postgres**는 TCP/IP를 사용하여 포트 **5432**를 통해 통신한다.  
- 웹 서버는 일반적으로 포트 **80(HTTP)** 또는 **443(HTTPS)** 을 통해 클라이언트 요청을 처리한다.

### 비유 요약
> 🏠 IP 주소 = 집 주소  
> 📬 포트 번호 = 우편함 또는 방 번호  
> 📦 TCP/IP = 우편을 전달하는 전체 시스템 (주소 + 우편함 + 배달 프로세스)
