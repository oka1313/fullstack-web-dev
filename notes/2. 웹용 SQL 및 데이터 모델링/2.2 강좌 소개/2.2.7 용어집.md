# 2.7 용어집

| 용어 | 설명 |
|------|------|
| **Flask** | 웹 애플리케이션을 빌드할 수 있는 파이썬 라이브러리.<br>웹 서버 프레임워크로서 앱의 프론트엔드를 제어하는 데 사용 |
| **SQL** | 관계형 데이터베이스에서 데이터와 상호 작용하고, 저장 및 구성하는 데 가장 일반적으로 사용되는 언어 중 하나 |
| **PostgreSQL** | 캘리포니아 대학교 컴퓨터 공학과에서 개발한 `ORDBMS`(Object Relational Database Management System, 객체 관계형 데이터베이스 관리 시스템) |
| **Postgress** | 파이썬 프로그래밍 언어에서 가장 많이 사용되는 `PostgreSQL` 어댑터.<br>핵심은 파이썬 데이터베이스 API 2.0 사양을 완벽하게 구현한 것.<br>여러 확장 기능을 통해 `PostgreSQL`이 제공하는 많은 기능에 액세스할 수 있음.<br>설정 및 설치가 간편하고 `SQL` 및 `NoSQL`을 지원하는 엔터프라이즈급 관계형 데이터베이스 시스템 |
| **psycopg** | 파이썬 프로그래밍 언어에 많이 사용되는 `PostgreSQL` 어댑터 |
| **SQLAlchemy** | 파이썬 앱과 데이터베이스 간의 상호 작용을 가능하게 하는 라이브러리 API |
| **Flask-SQLAlchemy** | `Flask`의 확장으로 `SQLAlchemy`에 대한 추가적인 지원을 제공.<br>이 확장 프로그램은 `Flask`를 사용하여 표준 `SQLAlchemy`를 간소화하고 유용한 기본값과 헬퍼를 제공하여 보다 쉽게 사용할 수 있도록 함. |
| **CRUD** | 모든 데이터베이스는 데이터를 생성하고(`Create`), 읽고(`Read`), 업데이트하고(`Update`), 삭제(`Delete`)할 수 있어야 함 |
| **관계형 데이터베이스** | 서로 연관된 데이터를 저장하고 이에 대한 액세스를 제공하는 데이터베이스 유형.<br>이는 여러 "연결된" 테이블을 통해 이루어짐. 테이블의 열에는 데이터의 속성이 저장되고, 테이블의 행에서는 각 속성에 대한 데이터를 보유함.<br>프로그래머는 키를 사용하여 데이터를 의미 있는 방식으로 간편하게 연결하여 데이터 요소 간의 관계를 설정할 수 있음. |
