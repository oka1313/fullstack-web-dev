# POSTGRES 모델링

## 📖 개요
이 논문은 POSTGRES 데이터 모델을 통한 SQL과 데이터 모델링에 대해 소개한다.

**원저자:** 로우, 스톤브레이커

주요 개념은 다음과 같다:
- 추상 데이터 유형
- 프로시저 유형 데이터
- 관계형 모델 확장을 위한 상속

이 논문은 예측할 수 없는 구성과 공유 하위 객체를 가진 복잡한 객체를 지원하는 데도 유용하다.
